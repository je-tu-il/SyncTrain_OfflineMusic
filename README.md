# 🖥️ SyncTrain OfflineMusic

> Fork Syncthing / SyncTrain P2P Hors Ligne & Lecteur Musical Aléatoire

Fork avancé de SyncTrain / Syncthing optimisé pour les trajets en mobilité : synchronisation maillée pair-à-pair directe en Wi-Fi / Bluetooth sans Internet, couplée à un lecteur de musique intégré jouant directement depuis les dossiers synchronisés en mode aléatoire.

---

## ⚡ Fonctionnalités Clés

- Synchronisation P2P sans connexion internet
- Partage instantané entre appareils proches
- Lecteur audio multi-dossiers avec shuffle intelligent
- Écoute musicale 100% nomade
- Échange de morceaux en train ou avion sans 4G
- Autonomie et souveraineté totale
- Score professionnel qualité : 100/100

---

## 🛠️ Stack Technique

- **Technologies** : Python 3.11, FastAPI, Syncthing Protocol P2P, Web Audio API, Docker
- **Catégorie** : Applications Desktop
- **Statut** : Production
